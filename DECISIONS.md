# Decisions (one line each)

- Editor: Unity 6000.3.29f1 LTS (installed; 6000.6 is not LTS). Build scripts read ProjectVersion.txt to locate it; `UNITY_EXE` overrides.
- Package id `com.supcom.mottainai` per spec (previously `com.greenhack.mottainai`; phones will see a new app).
- NGO 2.14.0 + Transport 2.7.4 (versions bundled with this editor). No NetworkObjects/prefabs: all traffic is NGO unnamed custom messages (1-byte type header), so "generated netcode prefabs" = none needed.
- Host loopback: in editor host mode, server<->local-client messages are delivered in-process by `NetBus` (no double delivery, no transport).
- One server process hosts many rooms (4-letter codes); snapshots are sent per room member, so rooms are isolated.
- Snapshots: per tick, entities in [-15 m, +60 m] around the raft, 10 bytes each (quantized pos/yaw/bob), split in chunks of 96 entities (<1.1 KB) on UnreliableSequenced; chunk 0 carries raft state + 4x4 flow-field samples. Own chunking instead of transport fragmentation so a lost packet only loses part of a frame.
- Inputs: unreliable-sequenced heartbeat every tick (seq + client interp delay); strokes/throws are Reliable messages.
- Raft physics is a custom kinematic model (velocity relative to water + flow field, forward/lateral drag, yaw kick with damping) — deterministic, no PhysX.
- Sync boost: second stroke within 0.25 s with same direction gets x1.3 impulse and damps yaw 70% so the raft goes straight.
- Lag compensation rewinds waste/raft positions by min(RTT/2 + client interpolation delay, 150 ms) using a 16-tick history ring (RTT from Unity Transport).
- Adaptive interpolation: render tick = max-filtered clock offset − max(1 tick, p95 snapshot lateness); shown in Net HUD.
- Bots: paddlers run a 3.2 s look-ahead planner over 15 stroke patterns on a copy of the raft sim (0/20 crashes, ~660 m avg in BotSimulation); with one human paddler the bot syncs with the human's strokes.
- Shark: 9.5 s cycle = 3 s submerged (harmless) + 1.5 s fin telegraph (harmless) + 5 s active patrol (±6 m @ 2 m/s).
- Free-lane guarantee: each 40 m chunk has a planned lane (3x raft width) with no static obstacles; validated per chunk, offending obstacles removed. Sharks may cross it (dynamic hazard).
- Dedicated Server module not installed for 6000.3 → Windows server = standard player built with `MOTTAINAI_SERVER_BUILD` (forces server mode; `-client` flag turns it back into a client for smoke tests). With the module installed, `BuildServerWindows/Linux` automatically use the Server subtarget. Linux build fails fast with a message if Linux module missing.
- Server code lives in the `Mottainai.Server` assembly excluded from Android/iOS (equivalent to `#if UNITY_SERVER`); registered through `AppHooks` via reflection (Unity skipped its init attribute in player builds).
- App start moved to `Start()` because NGO registers its message types in an AfterSceneLoad callback.
- HTTP: Mono `HttpListener` on `http://*:8080/` (works without admin on Windows with Mono); falls back to `+` then `localhost` with a warning.
- Content Pack: tuning.json + server.json + two 2048² RGBA water normal maps + 1024² raft skin = 36 MB, generated procedurally by the server (Kenney textures not downloadable, see below), MD5-cached on device, "FORCE RE-DOWNLOAD" toggle.
- Kenney/Quaternius CC0 kits: kenney.nl returns 403 / JS donation flow to scripted downloads → `VisualFactory` primitives are used (models dropped in `Resources/Models/<waste_plastic|obstacle_rock|...>` are picked up automatically).
- SFX procedurally synthesized (fallback); CC0 clips in `Resources/Audio/<splash|catch|...>` override automatically.
- Shaders: own URP HLSL Toon (lit, SRP-batcher, instancing), Transparent (fresnel bubble/net), Water (vertex sine + 2 scrolling normal maps from the pack + dirt tint near waste) — placed in `Resources/Shaders` so they are always in builds.
- TMP Essentials are extracted synchronously by SetupProject (AssetDatabase.ImportPackage is async and lost in batchmode).
- Android permissions (READ_PHONE_STATE, ACCESS/CHANGE_NETWORK_STATE, VIBRATE) injected by an `IPostGenerateGradleAndroidProject` patcher; cleartext HTTP allowed (`insecureHttpOption`), min API 26, IL2CPP ARM64.
- 5G detection + latency slice + haptics in a plain `.java` plugin (`Plugins/Android/NetInfoPlugin.java`) behind `INetworkInfoProvider`; iOS/desktop use `DefaultNetworkInfoProvider`.
- Network Lab echo uses an extra UDP port 7778 (Lab runs before/without a game connection).
- In-game RTT is measured with app-level ping/pong (includes frame quantization ~1 frame each side); Network Lab measures raw UDP RTT.
- Render scale starts at 1.0 and the PerfGovernor drops it to 0.8 after 3 s below 45 FPS; MSAA 2x, HDR and shadows off.
- Battle-mode hooks: `IGameMode`, `ModeConfig`, `TeamState` list, `HealthComponent`, per-team `ScoreService`; course spawner is team-independent.
- 5G SA latency: server tick configurable up to 120 Hz (`run_server.bat -tick 120`), sent to clients in MatchStart; interpolation floor drops to 1 tick (8 ms). Lag-comp history 32 ticks.
- Own-raft client prediction: paddler strokes are applied locally on a RaftSim copy re-simulated from the latest server state (+ one-way latency); errors decay exponentially (no snapping). Other entities stay interpolated.
- Client frame rate follows the display (up to 120 FPS on 120 Hz phones) for lower touch-to-photon latency; PerfGovernor drops render scale/MSAA if FPS < 45.
- Graphics: runtime URP Volume (bloom, neutral tonemap, color grading, vignette with hit/shield/sync pulses), procedural sky dome shader, water foam (banks, obstacles, raft wake) + glints, faceted procedural rocks/icebergs/trees, torus raft, hemispheric SH ambient. MSAA 4x on devices with ≥6 GB RAM.
- Menus render the live 3D river (attract mode) behind translucent panels.
- tools/compile_check.sh type-checks all scripts with Unity's bundled Roslyn while the editor is open (no batchmode needed).
- v2: Cloudflare Worker `mottainai` on workers.dev subdomain `mottainai-server`; assets binding serves /pack/*, Worker-first for /api/* and /ws/*.
- v2: RoomDO uses the WebSocket Hibernation API (ctx.acceptWebSocket); players restored from socket attachments after wake.
- v2: Room colo learned via `https://cloudflare.com/cdn-cgi/trace` from inside the DO (edge colo = request.cf.colo).
- v2: Snapshot = per-team raft block + 10-byte entities, window -15..+60 m; 30 Hz fallback when any STATS backlogMs > 100.
- v2: Strings = u8 length + UTF-8; client→server STROKE/BACKPADDLE carry u8 power (0..255).
- v2: npm install-scripts approved only for esbuild + workerd (wrangler requirements).
- v2 C1: interpolation stays in WorldView (per-entity ring buffers); delay target = max(2 snapshot intervals, jitter p95) + 0.35 tick.
- v2 C1: flow field no longer sent: client computes FlowField.Sample(seed) locally (deterministic).
- v2 C1: preferred role saved in PlayerPrefs and sent in the WS URL; server default order L, C, R (demo: phone A = L, phone B = C, bot = R).
- v2 C1: client keeps one stable token (PlayerPrefs) so a reconnect within 60 s restores the role.
- v2 C1: Network Lab room RTT uses a throwaway room `LAB####`; edge RTT via `<baseUrl>/cdn-cgi/trace` (fallback /api/lab/ping).
- v2 S1: sim ported to server/src/sim.ts (1:1 with C# Gameplay); course RNG = mulberry32 (client never regenerates the course, only renders snapshots).
- v2 S1: sharkSpeed back to the spec value 2 m/s (tuning.json is the single source; visibility fixes kept).
- v2 S1: bot paddler sync assist = mirrors the human partner's stroke after 30–100 ms with p = botSyncChance 0.8 unless the mirror leads into danger; otherwise the 15-policy planner steers.
- v2 S1: bot collector aims after a 0.3–0.6 s reaction delay; misses are thrown 35–57° off target (measured ~80% net accuracy incl. lucky catches).
- v2 S1: lag compensation rewinds NET by RTT/2 (from STATS), cap 150 ms; history 32 ticks (533 ms).
- v2 S1: DO loop = setInterval(1000/60) + fixed-step catch-up (max 4 steps); START in END state = rematch; mid-match join/reconnect takes the role back from the bot.
- v2 S1: content pack generated by server/tools/genpack.mjs at deploy time (not in git): 36 MB, sha256 manifest.
- P1 models: CC0/CC-BY models in Resources/Models/{Raft,Obstacles,Waste,Pickups}; VisualFactory falls back to primitives when a file is missing; credits in Models/CREDITS.md.
- P1 models: import rules in EditorTools/ModelImportRules.cs (file scale, Generic rig, anim only for shark, looped); size fitted at runtime (largest side: waste 0.8 m, shark 2.4 m, raft 3.4 m, paddle 1.34 m, shield kit 0.6 m).
- P1 models: imported materials swapped at runtime for Mottainai/Toon (color + texture kept); shark clip played via PlayableGraph (ModelLoop), no AnimatorController asset.
- P1 models: Metal = metal_can | metal_can_broken, Toxic = toxic_propane_tank | battery (random per entity); toxic model keeps the hazard billboard; shark model keeps the primitive fin (always-visible telegraph).
- P1 models: raft model replaces torus hull/rope/floor (Content Pack raft skin only applies to the torus hull); paddle auto-oriented blade-down at import.
- P1 models: glTFast 6.21.0 added for metal_can.glb (only GLB-only model). bear_trap.fbx imported but unmapped (no ObstacleType for it; needs server sim + protocol change).
- I1 test plan: 1 phone on this PC -> 1 human + 2 bots (LEFT PADDLER, then COLLECTOR); pass = 3 full matches in a row on 5G SA.
- NET: DO loop uses drift-free setTimeout chain aimed at ideal tick times (setInterval drifted 0.3 ms/tick: 0-16 ms sawtooth + 2-snapshot bursts). Measured server send jitter p95 14.7 -> 0.7 ms (tools/jitter.ts).
- NET: events flushed immediately after STROKE/NET input (teammates see strokes ~half a tick sooner); inputs arriving <=120 ms before their cooldown are deferred, not dropped.
- NET: client sets TCP_NODELAY via reflection (Mono ClientWebSocket measured NoDelay=False); RTT stamped on the socket thread; raft prediction timebase = server tick clock (best-arrival line + RTTmin/2), strokes acked by their EVENTS echo; jitter buffer = max(2 intervals, interval + p95 lateness); starved entities extrapolate up to 6 ticks; 120 Hz target drops to 60 if not sustained; MSAA capped at 2x.
- BUILD: tools/build_copy.sh builds from a robocopy mirror (.bc/) so APKs/Windows players can be built while the editor is open.
- ART: camera framing changed to the reference (raft ~32 deg below camera, horizon ~20% from top); visual sun top-right decoupled from key light (upper-right behind camera) so the toy crew stays front-lit.
- ART: Quality High/Low (PlayerPrefs qualityHigh; default High on >=5.5 GB / 8-core phones): Low disables post, sky rays, water caustics.
- ART: blob shadows drawn into the water FX map alpha (no extra draw calls); ripple rings/bow wave/splash rings in the FX map foam channel.
- ART: imported Elm/Palm GLB textures downscaled 2048 -> 1024 (budget), Nature pack rejected (66k tris). Rocks: 30% render as red/white buoys (visual only).
